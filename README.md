# 🤖 ML Algorithms Practice

A comprehensive collection of Machine Learning algorithm implementations built during Data Science training at ExcelR Solutions.

## 📌 Overview
Hands-on implementations of core ML algorithms applied to real-world datasets across classification, regression, clustering, NLP and more.

## 📂 Contents

| Algorithm | Dataset |
|---|---|
| Linear Regression | Toyota Corolla, 50 Startups |
| Logistic Regression | Bank Marketing |
| Decision Tree | Company Data, Fraud Detection |
| Random Forest | Multiple datasets |
| KNN | Zoo, Glass |
| SVM | Forest Fires |
| Naive Bayes | General |
| Neural Network | Forest Fires, Gas Turbine |
| Clustering | EastWest Airlines |
| PCA | Dimensionality Reduction |
| Association Rules | Market Basket |
| Recommendation System | Collaborative Filtering |
| Text Mining | NLP tasks |
| Time Series Forecasting | Forecasting |
| Hypothesis Testing | Statistical Analysis |

## 🛠️ Tech Stack
- Python, Scikit-Learn, TensorFlow, Keras
- Pandas, NumPy, Matplotlib, Seaborn
- Jupyter Notebook

## ▶️ How to Use
Open any `.ipynb` file in Jupyter Notebook or Google Colab and run the cells.
